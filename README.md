# 这里是ARCreeper模式的平衡包

ARCreeper客户端具体可见 https://github.com/CN-ARC/Mindustry-CN-ARC/tree/ARCreeper

## 使用说明

1、目前有主分支(旧包)，LC分支和lemonfox分支，后续也可能有其他人平衡的版本。你应该确认使用哪一个版本

其中，

LC版~~更倾向于将兵种严格分为多个种类并要求单位配合使用

lemonfox版~~单位的特效和攻击方式则更有创意和观赏性

2、接下来，使用ARCreeper最新客户端(自行编译或者群里下载)，下载你主分支的地图包(maps)

3、游戏时，先在编辑器里将地图里的平衡包及通用包删除，并使用这里最新的平衡包及通用包替换，根据需求使用单人模式包(推荐)，然后开始游戏

4、如果你想作图，可以使用地图里的逻辑，或者直接使用logic里的逻辑代码导入

5、不管怎样，推荐加群：781930752
